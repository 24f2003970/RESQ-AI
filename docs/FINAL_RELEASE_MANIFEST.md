## Generate a machine-readable manifest

Run `scripts/write-release-manifest.ps1` after the final build and local verification. The JSON output is ignored under `artifacts/part16-release-manifest.json` so it does not accidentally become a stale source-controlled manifest after a later commit. Review the output before sharing; it includes no user database or browser profile.

No zip is generated by default. If a source archive is needed after review, create it from the exact reviewed commit with `git archive`, then inspect its contents and hashes. Do not include local environments, `.env` files, databases, browser data, caches, or recordings. No Git tag, GitHub Release, hosted deployment, repository visibility change, or Innotech submission is performed by this process.
