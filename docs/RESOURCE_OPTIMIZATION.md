# Resource optimization

The optimizer uses SciPy's `linear_sum_assignment` to solve the maximum-weight bipartite assignment between compatible standby ground units and reachable destinations. One dummy column per unit permits unassigned units; inaccessible unit-destination pairs are excluded. Stable unit/destination ordering and a 1e-12 lexicographic score perturbation provide deterministic tie resolution; the reported optimum is for this explicitly tie-broken objective. The solver reports `optimal_linear_sum_assignment`. Its objective maximizes the sum of capacity-covered priority less 0.15 points per synthetic route minute, with each unit and destination assigned at most once. Unit capacity caps occupants targeted. Boat routing remains unsupported. A local stress run over 72 eligible destinations and the four compatible ground units measured **0.000160 seconds** for assignment (Windows, Python/SciPy; measured in `test_linear_assignment_scales_to_72_destinations`; route calculation excluded).

The baseline remains a transparent greedy comparison using the same unreserved inventory and reachable routes, choosing the nearest available unit in descending priority order. It is not represented as globally optimal.

Approval reserves every assigned unit for that scenario epoch. Subsequent proposals omit those units from both optimization and available assignments. A second pending proposal generated before the first is approved may contain the same units, but its approval is rejected if those units have since been reserved. There is no simulated mission completion or automatic resource release. Units become available again when the scenario is reset into a new epoch; this starts a fresh planning inventory.

Priority score is a transparent 0–100 synthetic planning index: 0.25 × capped occupants/100 + 0.25 × current exposure indicator + 0.15 × capped current depth/1.5 m + 0.10 × ML future exposure indicator + 0.10 × nearest-road access deterioration (0 open, 0.5 caution, 1 flooded/closed/manually blocked) + 0.10 × resource scarcity (one minus compatible unreserved standby units divided by eligible affected buildings, floored at zero) + 0.05 × facility criticality (1 hospital, 0.5 shelter). The ML future-exposure label is distinct from observed current flood state. This score is neither calibrated nor a life-safety triage standard.
