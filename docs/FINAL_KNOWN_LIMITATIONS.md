# Final known limitations

## Accepted prototype boundaries

- The city, rainfall and river inputs, flood response, building impacts, training labels, resource inventory, travel speeds, routes and mission outcomes are synthetic.
- The local random forest predicts a label generated by the same simulator family. Calibration and test metrics are synthetic evidence, not real flood forecast performance.
- Route feasibility is limited to the generated graph and encoded assumptions. It is not a surveyed road, traffic, bridge-load, emergency access, or field-safety assessment.
- Six agents are deterministic algorithms, not LLMs. Their recommendation does not replace command authority.
- Mission dispatch, movement, arrival, completion and return-to-service are simulations. They do not contact responders or establish that occupants were evacuated.
- The assignment optimizer maximizes its declared synthetic objective, not lives saved or guaranteed real response efficiency.
- The Part 15 evaluation contains ten selected condition groups; it is a bounded engineering comparison, not a statistical estimate of disaster performance.

## Verification limitations

Exact CSS viewports (1366×768, 1440×900, 1920×1080), full keyboard/screen-reader accessibility, reduced-motion preference, and WebGL context-loss recovery are BLOCKED for Part 16 because the computer-use helper could not verify the current Edge URL. The browser operation was not retried or bypassed; this is a tool safety restriction, not an app defect. Prior screenshots are genuine but include only selected screens and a browser-extension overlay. They are not newly verified Part 16 browser states.

Vite warns that the lazy CityScene bundle is larger than 500 kB. The code did not increase that bundle in the prior Part 14 measurements; Part 16 records a new build size. The application has also shown a non-blocking upstream `THREE.Clock` deprecation warning in prior browser observations. The historical React maximum-update-depth stack was never captured; later bounded walkthroughs did not reproduce it.

The offline audit confirms no required hosted inference or map service in the configured core demo and loopback service binding by default. There has been no formal penetration test or OS firewall isolation exercise. Dependency installation requires network access unless packages are already cached.

## Out of scope

Real disaster use, certified forecasting, earthquake simulation, live geospatial/hydrology feeds, responder dispatch integrations, boat rescue, operational privacy/security certification, regulatory review, and public deployment.
