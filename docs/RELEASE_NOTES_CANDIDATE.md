# RESQ-AI v1.0.0-rc-final — candidate notes

This is a proposed final candidate label for review, not a published release.

## Included

- Local synthetic flood Digital Twin and deterministic scenario replay.
- Local random-forest future-exposure estimates with grouped evaluation, calibration, and support warnings.
- Six deterministic agent stages with durable decision traces.
- Flood-aware graph routing, constrained assignment, explicit commander review, and simulated mission lifecycle.
- Scenario and robustness analysis, Judge Mode, Guided Demo, local preflight, and disposable acceptance workflows.
- Ten-case reproducible scientific comparison and an Innotech evidence/presentation kit.

## Verification state

See `PART_16_VERIFICATION.md` for exact test totals, warnings, build sizes, CI, browser checks and outstanding items. A successful synthetic acceptance workflow is not field certification.

## Known limitations

All places, flood conditions, labels, people, resources, routes and outcomes are synthetic. The generated road network is not surveyed. There is no live sensor feed, operational dispatch, boat routing, earthquake workflow, formal penetration test, or real-world outcome validation. See `FINAL_KNOWN_LIMITATIONS.md`.

## Distribution boundary

The candidate is intended for a local demonstration and engineering review. No GitHub Release, public hosting, or Innotech submission has been made.
